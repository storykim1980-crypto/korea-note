# SEOUL NOTE 수동 스크린리더 점검 안내

**목적:** 자동 검사로 확인하기 어려운 실제 음성 출력, 읽기 순서, 포커스 이동을 일본어·영어판에서 직접 확인한다.  
**상태:** 점검 절차 준비 완료. 이 문서 작성 환경에서는 NVDA/VoiceOver 음성 점검을 실행하지 않았다.  
**현재 자동 검사 기준선:** 2026-10-11(Asia/Seoul), Playwright 1.64.0 / Chromium headless shell. 공개용 빌드의 20개 HTML 경로를 320, 390, 768, 1440px 폭에서 확인(총 80개 경로·폭 조합): 가로 넘침 0건, 경로 응답 오류 0건, 이미지 로드 실패 0건, 콘솔·페이지 오류 0건, 실패 요청 0건. 일본어판은 320/390px, 영어판은 320/1440px 스크린샷도 육안으로 확인했다. Axe WCAG 2.1 A/AA 검사 22회(20개 페이지 + 양언어 체크리스트 열린 상태)에서 위반 0건.

**자동 상호작용 검사:** 양언어판에서 카테고리 필터·검색, 기본 및 변경 운임 계산, 체크리스트 열기/Escape 닫기/초점 복귀, 2일 플랜 생성, Seoul City Climate Card coverage FAQ 출처 포함을 확인했다. 영어판에서는 저장/저장된 항목만 보기, 언어 전환, NAVER/KakaoMap 한글·영문 혼합 검색어 인코딩과 안전한 새 탭 속성, TXT 내보내기, 인쇄 핸들러도 확인했다. 플래너 결과 상태에서 Axe 위반은 0건이었다. 이는 자동 검사이며 NVDA/VoiceOver 실제 음성 시험이나 WCAG 적합성 인증을 대신하지 않는다.

## 테스트 환경 준비

한 번에 한 가지 보조기술·브라우저 조합을 기록한다. 두 언어판을 각각 시험한다.

| 권장 조합 | 시작 / 빠른 탐색 |
|---|---|
| Windows · NVDA · Firefox 또는 Chrome | NVDA를 실행한 뒤 browse mode에서 `H`(다음 제목), `D`(landmark), `F`(폼 컨트롤), `K`(링크), `NVDA+F7`(요소 목록)을 사용한다. 명령이 동작하지 않으면 설치된 NVDA의 User Guide와 현재 browse/focus mode를 확인한다. 공식 NVDA User Guide(2026.1.1): [3](https://download.nvaccess.org/releases/2026.1.1/documentation/userGuide.html) |
| macOS · VoiceOver · Safari | `Command+F5`로 VoiceOver를 켠다. 기본 VO 키는 `Control+Option`이며, 설정에 따라 `Caps Lock`일 수 있다. `VO+U`로 rotor를 열어 제목·링크 목록을 탐색한다. Apple 공식 시작/rotor 안내: [2](https://support.apple.com/guide/voiceover/get-started-vo4be8816d70/mac), [1](https://support.apple.com/guide/voiceover/voiceover-rotor-mchlp2719/mac) |

설치된 보조기술 버전에 따라 키 조합이나 발화는 다를 수 있으므로, 실제 설치 버전의 공식 안내를 우선한다.

## 점검 항목

각 항목마다 **PASS / FAIL / 해당 없음**을 표시하고, 가능하면 실제로 들은 문구를 그대로 적는다. “자동검사 통과”를 이유로 실제 발화를 추정하지 않는다.

| ID | 확인할 동작 | 통과 기준 | 결과 / 실제 발화·문제 |
|---|---|---|---|

| SR-02 | 첫 `Tab`과 스킵 링크 | 첫 키보드 정지가 `本文へスキップ` / `Skip to content`이다. 포커스가 눈에 보이고 실행하면 본문으로 이동한다. |  |
| SR-03 | 랜드마크·제목 탐색 | banner/header, navigation, main, footer/contentinfo를 구분해 탐색할 수 있고, 제목 단계가 내용을 설명한다. |  |

| SR-13 | 현지 긴급·관광 연락처 | 112(경찰)·119(소방/구급)와 1330(비긴급 관광 안내/통역)의 목적 차이를 듣고 구분할 수 있다. 번호 링크의 목적·발신 번호(한국 내 1330, 해외 +82-2-1330), 일본어 지원 안내, 한국어 참고 문구와 공식 출처 링크를 탐색할 수 있다. |  |

### 빠른 계산기 재현값

1. 단기권을 **3일**, 이동 횟수를 **8**, 신규 실물 카드 비용을 **포함**으로 둔다. 예상 발화는 두 합계를 구분해야 한다: 일반 기본운임 **₩12,400**, Climate Card **₩13,000**, 기본운임만의 비교에서는 일반 운임이 약 **₩600 낮음**.
2. 신규 카드 비용을 끄면 Climate Card 금액은 **₩10,000**이 된다.
3. 다른 날짜 수·이동 횟수로 바꿔 결과가 갱신되는지 확인한다. 모든 결과는 제한사항을 함께 안내해야 하며, 실제 노선별 절약액으로 단정하면 안 된다.

## 문제 기록 기준

- **차단/중대:** 주요 항목에 키보드나 스크린리더로 접근할 수 없음, 대화상자에서 빠져나올 수 없음, 핵심 입국·요금 정보가 전달되지 않음.
- **주요:** 컨트롤 이름·상태·계산 결과 갱신이 전달되지 않거나 초점이 사라짐/잘못 이동함.
- **경미:** 발음·반복·읽기 순서가 다소 어색하지만 작업을 완료할 수 있음.

## 결과 전달 시 포함할 것

1. 위 환경 정보와 FAIL 항목의 ID.
2. 예상한 결과와 실제로 들린 문구(개인정보는 제외).
3. 재현을 위한 키 입력 순서와 페이지 언어·화면 폭.
4. 가능하면 문제가 발생한 위치의 스크린샷. 스크린샷에 여권·주소·의료정보를 넣지 않는다.

이 점검표는 실제 NVDA/VoiceOver 세션을 대신하지 않는다. 시험을 완료하면 결과를 기록해 주면, 확인된 문제를 수정한 뒤 동일 조건으로 재시험할 수 있다.
