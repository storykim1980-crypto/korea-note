# 폰트·문장 배열 검토 — 2026-10-12

## 적용 기준

- 요청한 참고 사이트: https://www.his-vacation.com/
- 페이지 텍스트는 조회했지만, 직접 HTTP 요청 및 Chromium 렌더링은 403 응답이었다. 실제 HIS CSS의 font-family, 크기, 사용 글꼴은 확인하지 못했다. 이 구현은 HIS와 동일한 폰트라고 인증한 것이 아니다.
- 일본어: Arial(영문·숫자), メイリオ/Meiryo, ヒラギノ角ゴ Pro W3/Hiragino Kaku Gothic ProN, Hiragino Sans, sans-serif 순으로 시스템 글꼴 사용. 설치 글꼴에 따라 결과가 달라진다. Windows/macOS/iOS/Android 실기기 확인은 남아 있다.
- 이전 Noto Sans JP 웹폰트와 라이선스 파일을 공개 빌드에서 제거했다. 더 이상 4.2MB 글꼴 다운로드가 없다. 공개 파일은 다시 38개다.
- 본문과 가이드: PC 18px / 모바일 17.5px, 가이드 행간 1.85. 카드 본문 17px, 카드 제목 PC 22px / 모바일 21px. 보조 텍스트는 역할에 따라 14–16px. 입력창은 16px 이상을 유지하도록 기존 크기를 조정했다.
- 기사 읽기 영역은 최대 800px, 모바일 좌우 여백 16px. 큰 홈 제목은 PC 최대 60px, 모바일 30–40px의 유동 크기다.
- 제목에 text-wrap:balance, 일본어에 line-break:strict를 사용한다. 제목의 불필요한 강제 br을 제거했다. 용어 설명·짧은 목록·보조 문구에도 측정 결과에 따라 균형 줄바꿈을 적용했다. 미지원 브라우저는 자연 줄바꿈으로 표시한다.

## 브라우저 실측 결과

`qa_line_widths.cjs`는 document.fonts.ready 이후 각 문자를 DOM Range로 선택하고 getClientRects()의 위치를 수집한다. 같은 높이의 글자를 하나의 줄로 묶어 실제 줄 너비, 사용 가능한 너비, 마지막 줄 글자 수, 요소 경계 밖으로 나간 글자를 기록한다. 문자열 길이만으로 너비를 추정하지 않는다.

- 23개 경로(404 포함) × 6개 너비(320/390/768/1024/1280/1440) = **138개 조합**
- 요소/문서 경계 넘침 **0건**
- 마지막 줄 1–2글자 또는 제목 마지막 줄 점유율 18% 미만의 검토 후보: 최초 190건 → 제목 조정 후 7건 → 최종 **0건**
- 세부 결과: `line-width-report.json`
- 별도 기존 회귀 검사: 22개 콘텐츠 경로 × 6개 너비 **132개 통과**
- Axe WCAG 2.1 A/AA: **28개 상태, 위반 0건**
- 두 언어 390/1024px 검색·필터·저장·메뉴·체크리스트 상호작용 통과
- 정적 검사 통과

이 수치는 해당 Chromium 환경에서 정한 규칙에 걸린 항목 수다. 자연스러운 의미 단위의 줄바꿈, 일본어 품질 또는 모든 기기에서의 동일 표시를 인증하지 않는다. 시스템 글꼴이 다른 OS 및 Safari/Firefox에서는 재검사가 필요하다.

## 재실행

공개 빌드를 먼저 재생성한 뒤 로컬 정적 서버로 제공한다. Node.js 환경에 `playwright` 및 Chromium/필요 OS 라이브러리를 설치한다.

```sh
python3 research/build_culture_articles.py
python3 build_public_site.py
# 별도 터미널: python3 -m http.server 4173 --directory ../seoul-note-public
BASE_URL=http://127.0.0.1:4173 node research/qa_line_widths.cjs
python3 research/qa_static_site.py
```

스크립트는 연구 자료로만 보관하며 공개 사이트에 배포하지 않는다. 모듈을 별도 폴더에 설치한 경우 NODE_PATH를 해당 node_modules로 설정한다.

## 일본어 문구 검토 범위

AI 편집으로 홈페이지 도입문을 더 직접적인 문장으로 수정했다.

- 이전: 韓国の文化、ことば、食、街歩き。公的機関や一次情報をもとに、背景と実用メモを日本語で紹介します。
- 수정: 韓国の文化やことば、食、街歩きを紹介します。公的機関の資料や一次情報をもとに、文化の背景と旅に役立つ情報を日本語でわかりやすくまとめました。
- 보조 문구: 出典をたどれる韓国情報ガイド → 出典を確認できる韓国情報ガイド

사실관계와 출처 날짜는 이번 시각 디자인 변경에서 새로 검증한 것으로 표시하지 않았다. 전체 기사에 대한 전문 일본어 교정 완료를 주장하지 않는다.
